# appier_scaffold

**🏗️ Starter scaffold for Appier web apps with authentication baked in 🐝**

</div>

---

## Installation

```bash
git clone https://github.com/tsilva/appier_scaffold.git
cd appier_scaffold
pip install -e .
```

## Usage

Use this scaffold as a starting point for new Appier web applications. It includes authentication controllers, account models, templates, and static assets.

```bash
python src/test.py
```
